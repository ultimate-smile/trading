# 简易量化交易系统（Python）

这是一个基于 Python + AkShare 的示例量化交易脚本，交易对象固定为：

- `000988`
- `688387`

## 交易逻辑

脚本每 `5` 秒轮询一次行情，并按以下规则发出信号（示例为“纸上交易”）：

- **买点**：当前价 `<= 5日均价 + 1`
- **卖点**：当前价 `>= 5日均价 * 1.05`（即高于 5 日均价 5%）

## 安装依赖

```bash
pip install -r requirements.txt
```

## 运行

```bash
python quant_trading_system.py
```

## 说明

- 该脚本仅做教学/研究用途，不构成投资建议。
- 当前实现为示例“下单器”，仅在内存里维护持仓并打印买卖日志。
- 如果你后续希望接实盘券商接口，可在 `place_buy_order` / `place_sell_order` 中接入交易 API。
